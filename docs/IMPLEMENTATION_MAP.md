- [Actual files on disk](FILE_MAP.md): implemented source and existing documents.
- [Detailed v0.2 plan](V0.2-PLAN.md): scope, ownership, numerical strategy and work sequence.
- [Planned files and contracts](v0.2/FILES.md): additions and explicit v0.1 migrations.
- [Test and acceptance plan](v0.2/TESTS.md): independent evidence and quantitative coverage.
- [Work packages](v0.2/WORK_PACKAGES.json): dependencies, effort ranges and exit gates.
- [Acceptance manifest](../test-manifest/v0.2-acceptance.json): planned criteria, all unexecuted.
- [Current status](STATUS.md): observed v0.1 validation.

Planned files are specifications, not empty stubs or implemented behavior. [Plan.md](../Plan.md) remains authoritative; no runtime version or completion claim changes merely because a planning file exists.
