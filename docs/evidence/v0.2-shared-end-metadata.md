`build/oracle-captures/shared-end-far-seed0-20260930a`. The first GPU attempt
fails 887/65,536 storage states in the negative case, before writing an artifact

corrected Vulkan flags produces the same 887 differences, excluding the

the End leaf: six of eight interpolation corners differ, first at
`(-2040,16,-2048)`, GPU `0.07451474666595459`, CPU `-0.0625`.

Both End shader paths used signed GLSL `% 2`, whose negative-operand result is
undefined by the [GLSL specification](https://registry.khronos.org/OpenGL/specs/gl/GLSLangSpec.4.60.html).
They now form Java's remainder by subtracting twice the truncating quotient.
Simplex attenuation also preserves the original left-associated subtraction,
instead of regrouping the squared-coordinate sum. The failure is retained in
`gpu-shared-end-far-corpus-seed0-20260930a` and
`gpu-end-far-static-flags-control-20260930a`; neither is passing evidence.

The corrected serial run
`build/gpu-shared-end-far-corpus-seed0-signed-fix-20260930a/replay-report.json`

- 20 independent original-only Minecraft fields; zero differences.

## Vulkan pipeline flags and compilation counters

The previous fluent builder incorrectly assigned the pipeline optimization
bit to `VkPipelineShaderStageCreateInfo.flags`. The corrected code writes it
to `VkComputePipelineCreateInfo.flags`, keeps shader-stage flags zero, verifies
both before native creation, and bumps internal cache identity to
`tellurium-captured-v3-compute-flags`. Old timings cannot be interpreted as
measurements of their nominal optimization policy.

Actual-device `nativeRawChainSuffixSmoke` passes both compute flag values 0/1,
requires one new native pipeline for the changed policy, and requires a cache
hit for its repeated use. The suffix/export, budget-shrink/regrowth,
recreation, 37/7/1-slice and 16,383-row partial-tail controls also pass.

Successful GPU receipts now expose executor-lifetime shaderc and native
pipeline hit/count/time counters. The corrected negative case records 63
shaderc compilations (2.20 s) and 92 pipeline creations (36.05 s), within
38.41 s aggregate execution wall time. The second case adds zero shaderc
compilations and 87 small pipeline creations (12.29 ms); its cumulative
execution delta is 143.61 ms. These are same-process observations including
host and driver work, not isolated kernel timing or sustained/live TPS. Do not
subtract overlapping timers to infer a throughput gate.
