## Implemented correction and checks

The shared `wg_i32_floor_div` now divides unsigned magnitudes and applies
Java's floor adjustment through wrapping integer carriers. This preserves
`Integer.MIN_VALUE / -1`, handles all divisor signs and marks divide-by-zero
as failed. `floor_mod` uses the carrier identity `a - floorDiv(a,b)*b`.
Both interpolation cell helpers use this floor operation; negative signed
remainder is no longer used at those boundaries. Unknown/failing inputs are
not replaced by CPU answers.

on RTX 5070 Ti: **1,684 operand pairs at batches 1, 63 and 1,684**, including

random inputs. All **20,208 output words** match Java quotient/remainder and
