- Distinct captured FlatCache producers previously shared `root/holder` as a
  value-cache identity. An ordered CPU trace proved that erosion reused the
  continentalness producer at `(512,64,520)`. Source-identity marker keys fix

  `0.12996654212474823`.

  of manufacturing duplicate noise subgraphs for each spline occurrence.

  spline module returned endpoint `6.3` rather than `4.69`; an independently
  staged all-GPU coordinate/spline evaluation matched the CPU at `4.69`.
  Literal constant knots remain inline so they need no extra dispatch.
- The optional stage oracle compares every coordinate, not just the first.

## Shared metadata and linear host packing

The generic Perlin sampler now reads one immutable metadata suffix after each
batch's ten-word sample rows. `RawRequest.slice` preserves that suffix and the
shader addresses it using the current `dispatch.count`, so a partial batch
does not reuse the full-request offset. The unrolled fallback keeps its
existing per-row format. No density/noise value is CPU-seeded by this change.
The shared path also avoids allocating an unused resident-chain scratch row.

Direct/embedded noise packing, interpolation corner packing, paired-result
splitting and diagnostic loops now copy each immutable `RawResult` once rather
than cloning its complete array inside the per-sample loop. The public result
ownership contract is unchanged; no mutable backing-array accessor is exposed.
