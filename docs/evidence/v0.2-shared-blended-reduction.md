## Implemented containment

The compiler-owned `SharedBlendedReductionStageEmitter` no longer carries the
captured graph, coordinate setup or dozens of restoring divisions into the
final fan-in module. Its fixed integer-only ABI is:

- 84-word sample row: four coordinate/reserved words, eight main FP64 samples,
  sixteen min-limit samples, sixteen max-limit samples, each in octave order.
- Prepare output: eight words, copied coordinates, ordered main sum at 4/5,
  exact denominator ten at 6/7.
- Main sum/ten uses the existing proven 29-dispatch shared FP64 divider.
- Finish input: the same 84 sample words plus that GPU quotient at 84/85;
  output: two raw FP64 words.

Only divisions by exactly representable normal powers of two are replaced by
integer-IEEE multiplication by their exact reciprocal. Non-power-of-two
division by ten remains the original staged restoring arithmetic. Both CPU
identity vectors and physical controls challenge subnormals and signed zero;
there is no native floating-point approximation. Accumulation order, clamp and
lerp operation order are preserved. Min/max sample reads stay inside their
original lazy branch conditions. Nonfinite used values fail closed.

The host only canonically packs GPU-produced sample/quotient carriers. It
rejects incomplete, duplicate, unknown or out-of-range groups and incompatible
row lengths, and owns its packed arrays. Interleaved captured min/max calls
are explicitly reordered; no CPU density or sample results are supplied.

The new exact-profile candidate uses this reduction by default.
`worldgennext.gpuCandidate.sharedBlendedReduction=false` retains the old
diagnostic module. Native-draft behavior is unchanged. This default is still
isolated/prototype execution, not qualified live generation.

## Prototype debt

An owned resident short chain may remove that traffic later, but the failed
long divider chain must not become the default. Primitive receipts remain
console-only. Larger finite-but-overflowing synthetic reductions are rejected,
not treated as successful terrain. Complete snapshots still carry large
captured source text and the remaining JVM graph caches are outside the binary

still required; cold/warm compilation observations are not a TPS claim.
