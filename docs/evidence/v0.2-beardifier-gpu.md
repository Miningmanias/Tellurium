## Counterexamples and fixes

The pinned Terralith seed-0 negative/positive preflight failed closed in shader
emission: `GPU_IEEE_BITS cannot emit beardifier (FP64)`. Its owned group exited
with `PROCESS_FAILED`, with no successful artifact or receipt. Retained roots:
`build/gpu-terralith-seed0-pair-byte-cache-20260930a` and its corresponding
`build/run/gpu-terralith-seed0-pair-byte-cache-20260930a`.

The compiler now implements captured `ProgramNode.Beardifier` in FP64 and
FP32. Empty captures return exact positive zero; nonempty captures use the
request's immutable pieces/junctions and the integer IEEE emitter. Repeated
markers share one helper body. Unrelated compacted stages drop the 13,824-word
kernel table only when no retained function references it.

Two existing standalone helper defects were exposed and corrected:

- Fast inverse square root accidentally multiplied the estimate three times
  instead of the original two left-associated factors.
- Combined density rows have six words, not the ordinary four-word coordinate
  stride. Coordinate loading now uses the actual row layout.

The GLSL-reserved local name `half` was also replaced with `halfValue`.
Standalone stages select their helper closure from the compiler-owned integer
emitter; no native floating-point or CPU final-density substitute is introduced.

## Physical primitive control

`NativeBeardifierSmoke` independently evaluates ordinary Java formulas and
computes kernel entries rather than using `BeardifierEvaluator`. Its 112 points
cover negative coordinates, the kernel's inclusive/exclusive boundaries, all
five terrain adjustments and two junctions. Both ordinary and density-combine
row layouts run with optimization disabled/enabled and slices of 112 and 7.
Reserved row words contain a poison value and must not participate.

The first broad `DontInline` physical control failed at its first fence with
`VK_ERROR_DEVICE_LOST (-4)` and exited without a passing comparison. The
subsequent compact helper-closure/inline-helper control passed all eight runs:
**896 exact raw-bit comparisons**, zero differences. These controls changed
source closure and compilation policy; they do not isolate a single causal
explanation for the device loss or qualify other drivers.
