This is a narrow P05/P06 runtime witness. It proves that the persistent
Tellurium Vulkan executor can compile and dispatch emitted `GPU_IEEE_BITS`
worldgen shaders on a real device, read back device-produced state IDs, and
retire the native resources. It is not the v0.2 GPU terrain qualification
gate.

The density fixture submits four coordinate triples as two bounded queue
dispatches (three elements and a one-element tail). The shader evaluates
`x + 1` using the raw integer-carrier helpers and writes the selected
default/air state ID from the device output buffer. The captured-noise fixture
submits six triples as three two-element dispatches, evaluates a captured
permutation table, octave stack, interpolation and raw binary64 path on the
device, and returns `[17, 23, 23, 23, 23, 23]`. The aquifer metadata fixture
emits one fluid candidate through the two-word raw output ABI and returns
`[31, 1]` (state ID 31, schedule-fluid-update mark 1). The ore fixture submits
four triples as two two-element dispatches, evaluates the captured positional legacy
RNG and six-entry copper/iron/ore/raw/filler rule on the device, and returns
`[106, 17, 17, 17]`. The second ore fixture uses the same coordinates with a
captured xoroshiro state and returns `[106, 103, 17, 17]`, proving the alternate
RNG branch is device-produced as well. The aquifer fixture submits four triples
as two two-element dispatches, selects the nearest captured cell candidate and
returns `[31, 31, 23, 23]`; the candidate state wins material precedence over
solid density, including the explicit AIR state returned by a dry aquifer
status. The executor allowlist explicitly admits the six ore and six aquifer
fixture material IDs in addition to default/air/invalid. Shaderc
compilation and SPIR-V numeric-contract inspection happen before dispatch; a
persistent instance/device/queue is used for the executor lifetime.

The result does not include the full captured Minecraft material program or
Minecraft aquifer parity, registry-table upload, structure/blend upload, live
chunk publication, FULL completion, or SAVED/reopened comparison. The aquifer
and ore fixtures are bounded synthetic captures and are not Minecraft
same-stack parity evidence. No GPU terrain qualification is claimed, and the
production Minecraft hook remains disabled.

## Native-runtime review follow-ups

The persistent executor now has bounded fence/device-loss handling: an
unproven completion marks the device lost, preserves the affected native
allocation in a charged quarantine ledger, advances the device generation,
and rejects late results. Its session-local native-pipeline cache is a bounded
LRU with explicit eviction disposal; SPIR-V binaries remain separately keyed.
Those focused lifecycle contracts are covered by injected tests and the
native asynchronous witness above. A live Minecraft generation service still
requires the separate P09 qualification and is not implied by this report.
