# v0.2 CPU candidate NOISE corpus evidence

Date: 2026-09-13. Workspace: `D:\Projects\WorldgenNext`. Scope: an executed same-stack CPU candidate corpus against the independent original-only Minecraft corpus. This is a P04/G4 witness, not a completed v0.2 release qualification.

## Command and isolation

The candidate was produced by the opt-in `WorldgenNext` NeoForge 21.1.176 / Minecraft 1.21.1 development server. Each case used a distinct server run directory and candidate output path. The candidate path is an artifact producer only; it does not install or invoke the production generation hook. The original inputs are the frozen `.snap` files under `build/oracle-captures/original`, produced by the standalone `oracle-1211` module described in [the original-oracle evidence](v0.2-original-oracle.md).

```powershell
$env:JAVA_HOME = 'C:\Program Files\Eclipse Adoptium\jdk-21.0.12.101-hotspot'
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\replay-minecraft-noise-cpu.ps1 `
  -ExpectedRoot .\build\oracle-captures\v02-vanilla-core\vanilla-overworld `
  -OutputRoot .\build\cpu-candidates\v02-vanilla-core-750-20260913 `
  -RunRoot .\build\run\cpu-candidates-v02-vanilla-core-750-20260913
```

The script resolved the candidate output property to an absolute path at the Gradle `runServer` boundary. This matters because the development server changes its JVM working directory before the mod reads the property.

`-Resume` path. No candidate artifacts were regenerated or overwritten; the
refresh only re-compared the existing files and persisted the aggregate
coverage fields (`comparedFields=7500`, `mismatches=0`,

## Vanilla dimension routing smoke

After the Overworld preflight, the same isolated artifact path was exercised
with `-Dworldgennext.*.dimension` set to `minecraft:the_nether` and
`minecraft:the_end`, using separate original and candidate server worlds. Each
one-case comparison passed all ten logical fields and compared 65,536 block
states with zero mismatches. This run also caught and fixed a geometry defect:
the Nether's 128-block logical noise range must be represented inside its
256-block ChunkAccess storage height; the candidate now emits an explicit air
tail above the logical range. These two cases are a routing/geometry smoke,
not additional G4 corpus coverage.

## Limits

This document records the executed 750-case three-dimension vanilla CPU slice.
The separate Terralith, Tectonic and combined terrain-mod evidence now adds
750 cases, completing the 1,500-case six-context CPU NOISE corpus; see
[v0.2-terrain-mods.md](v0.2-terrain-mods.md). The combined CPU corpus still
does not prove qualified GPU execution, GPU-issued receipts, live
interception, atomic commit/rollback, FULL downstream parity, the required
FULL/SAVED matrix, performance, or stability. The release manifest therefore
remains `executionStatus: NOT_RUN`, and the live hook remains disabled.
