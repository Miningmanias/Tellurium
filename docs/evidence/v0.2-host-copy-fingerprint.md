# v0.2 host-copy and fingerprint continuation — 2026-09-30

This is prototype containment/host-allocation work, not measured live TPS,
production-hook admission or completion of the six-context GPU corpus.

## Changes

`RawRequest` is an immutable final class with the existing constructors,
accessors and policy/slice methods. Public constructors/getters remain
defensive. Policy-only derivatives share request-owned immutable storage;
newly allocated slices no longer clone their rows/suffix a second time. The
private owned-input route is not publicly exposed. Native submission, numerical
source, buffer/fence/quarantine limits and pipeline bounds are unchanged.
Seven pure tests cover external mutation, internal sharing, all constructor
shapes, policies, nested/tail suffix slices and invalid inputs. Record reflection
is no longer available; this prototype API representation change needs review
before external integrations are declared stable.

Program and node fingerprints now stream exactly the existing canonical UTF-8
headers/child braces into SHA-256. A per-computation identity map memoizes only
local node-header bytes, not expanded subtrees; no global cache is introduced.
Four independent frozen-legacy-serializer tests cover shared DAGs, captured
noise/permutations, nested splines, Unicode, ordering, numeric profiles, control
regions and additional node headers. This preserves semantic identities; it
does not change graph operations or canonical format.

## Cleanup and measurement boundaries

Class/resource freezing and subset merging are harness conveniences. Bind
generation-start compiled inputs to every receipt; recovery/comparison hashing
does not retrospectively prove all earlier source provenance. Installed-jar
execution is a separate product gate from the current development launch.

Streaming still traverses the expanded canonical child sequence and retains
existing recursive spline-header/control-region string formatting. Bound deep
graphs and qualify more large captures before changing the canonical schema.
Request sharing still leaves constructor/readback/host-packing copies; a unified
host-memory budget and bounded resident transitions remain work.

The fixture timings contain CPU oracle, bootstrap, graph planning, cold/warm
compilation and host traffic. They are not five paired compile-free live runs,
nor NOISE/FULL chunks/sec. Measure phases and sustained live completion after
correctness/admission gates pass before claiming a TPS improvement.
