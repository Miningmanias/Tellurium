# v0.2 original-only Minecraft oracle evidence

Date: 2026-09-13. Workspace: `D:\Projects\WorldgenNext`. Scope: executed P01 oracle slices only; this is not a completed v0.2 qualification report.

## Isolation and capture path

`oracle-1211` is a standalone NeoForge 21.1.176 / Minecraft 1.21.1 development module. Its `worldgennext_oracle` mod imports only Minecraft, NeoForge and logging APIs. It does not depend on `WorldgenNext`, `oracle-and-replay`, the compiler, the Vulkan runtime or the product mod. The clean server launch reported only Minecraft, NeoForge and `WorldgenNext Independent Oracle` in its mod list.

Each run uses a distinct run directory and a generated `eula.txt`/`server.properties` owned by the capture task. The mod requests the original server's `ChunkStatus.NOISE` chunk and serializes it with Minecraft's `ChunkSerializer` before stopping the server. Capture failures or stale output fail `:oracle-1211:oracleSmoke` instead of allowing a previous artifact to pass.

The snapshot canonicalizer decodes paletted block-state and biome sections, sorts semantic palette values and remaps decoded indices. This avoids treating worker-dependent palette numbering as terrain differences while retaining meaningful state/property changes. Other fields remain field-specific canonical NBT projections; no compressed region bytes or checksum-only equality is used.
