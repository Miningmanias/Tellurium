# v0.2 isolated End GPU candidate smoke

This is a narrow GPU-candidate parity witness for the version-pinned
Minecraft 1.21.1 End route. It proves that the staged End noise lowering can
compile, dispatch and return device-produced block-state IDs, agree with the
same captured input materialized by the CPU candidate, and match an
independently captured original result at the exact same seed, dimension and
coordinate. It is not the complete six-context corpus or production GPU
terrain qualification.

## Executed command

```powershell
$env:JAVA_HOME = 'C:\Program Files\Eclipse Adoptium\jdk-21.0.12.101-hotspot'
.\gradlew.bat :neoforge-1211:gpuCandidateSmoke --no-daemon --console=plain `
  -Dworldgennext.gpuCandidate.capture=true `
  -Dworldgennext.candidate.capture=true `
  -Dworldgennext.candidate.output=D:/Projects/WorldgenNext/build/gpu-end-current7-20260913.chunk `
  -Dworldgennext.candidate.runDir=D:/Projects/WorldgenNext/build/run/gpu-end-current7-20260913 `
  -Dworldgennext.candidate.seed=0 `
  -Dworldgennext.candidate.chunkX=-32 `
  -Dworldgennext.candidate.chunkZ=-32 `
  -Dworldgennext.candidate.dimension=minecraft:the_end `
  -Dworldgennext.gpuCandidate.batchElements=128
```

Environment: Windows x64, Java 21, Vulkan 1.2, NVIDIA GeForce RTX 5070 Ti.

The staged End lowering resolves the exact generated blended-noise Perlin
function names and keeps the main/min/max octave groups distinct. The device
receipt records the captured snapshot fingerprint
`7eb931c42dd4cbe6fe897896cd23be5f02b19c73f03407033a12763b5431ad1b` and
the result checksum above. The driver advertises IEEE rounding and signed
zero/Inf/NaN preservation, but not binary64 denormal preservation; this run
therefore remains on the explicitly named `GPU_IEEE_BITS` route and does not
claim strict FP64 qualification.

This is one vanilla End NOISE case only. It does not establish the required
1,500-case six-context corpus, complete aquifer/material coverage, required
Overworld/Nether/modded GPU contexts, FULL, SAVED/reopen, live publication,
terrain-mod compatibility or sustained throughput. The production Minecraft
hook remains disabled.
