# Troubleshooting

`CPU_ONLY` with native initialization calls greater than zero is a failure. `GPU_REQUIRED` without a qualified physical device is an expected failure, not a CPU pass. A missing comparison, recovery route, stale commit, save barrier or reopened snapshot is also a failed endpoint.

Use `:verifyV02Inputs`, the focused contract tasks, and `scripts/qualify-v02.ps1` for driver-free checks. Use the opt-in native/game tasks only on a disposable dedicated run directory; a launched process is not evidence of parity.
