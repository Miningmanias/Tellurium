# Spatial data

`TileKey` identifies a reusable tile by world seed/dimension/graph/epoch, producer, domain, dependency hash, tile coordinates and width. `atChunk` uses floor division for negative coordinates and long arithmetic for origins. The caller must include every dynamic dependency in the identities; this module cannot discover omitted dependencies.

`ByteBudget` provides nonblocking, overflow-safe reservation and idempotent release. `SharedTileCache` reserves payload bytes before scheduling one producer per resident key. Consumers hold explicit leases and receive defensive byte copies. Active leases and unfinished producers prevent eviction. Completed unpinned entries use LRU eviction; failures retire after their last lease. Closing the cache rejects admission and defers reservation release until producers and leases finish. Cancelling one consumer future cannot cancel the shared producer.

Both payload bytes and resident entry count are bounded. These bounds do not include JVM object overhead, transient defensive copies or consumer-owned results. A caller-supplied executor owns scheduling and termination; cache close does not interrupt producer code. `AsyncSampleProducer` and `acquireAsync` let a coordinator hand off delayed samples without joining a stage on its worker; shared reservations remain held until the producer completes and all consumer interests are released. `TiledSampleConsumer` is the first demand-driven consumer: it splits a requested XYZ/halo window into bounded exact tiles, limits in-flight tiles, propagates cancellation and returns a higher-level `SampleWindow` lease. It tracks pending windows and closes them on shutdown; completed windows remain caller-owned until their explicit close. Typed column, surface and aquifer adapters therefore receive only the partial tile they can actually satisfy instead of a giant regional ticket. Actual Minecraft regional sampling, native arenas and graph dependency derivation remain future work.

Run `./gradlew :spatial-data:test` on JDK 21. Tests cover extreme/negative tile reconstruction, semantic identity partitioning, concurrent budget admission, one-producer contention, synchronous and asynchronous future isolation, eviction, malformed producer results, rejected executors, bounded demand splitting, typed partial edges and close while production is pending.
